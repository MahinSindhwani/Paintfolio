# paint-portfolio

A Windows 95 MS Paint recreation that is also my portfolio. The Paint UI is the
real interface: toolbar buttons navigate, the palette recolors the site.

Stack: Vite + TypeScript, no framework, plain CSS, 98.css for base chrome.

- `npm run dev` — dev server
- `npm run build` — typecheck + production build

Full spec lives in [CLAUDE.md](CLAUDE.md).
